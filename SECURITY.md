# Security

Please report a vulnerability privately, not in a public issue:

- through GitHub: **Security → Report a vulnerability** on this repository, or
- by email to **support@anonalabs.com** with "security" in the subject.

Include what you found, how to reproduce it and what it affects. We will confirm receipt and
keep you updated while we fix it. This covers the code in this repository and the Anona Compute
service it talks to.
